View Transitions Mock

A non-visual, spec-compliant polyfill for Same-Document and Element-Scoped View Transitions.

The Mock

view-transitions-mock polyfills the full JavaScript API surface of Same-Document View Transitions without the animations, so you can drop if (document.startViewTransition) and if ("startViewTransition" in Element.prototype) guards from your codebase:

  • Document-Scoped View Transitions: document.startViewTransition(), document.activeViewTransition, and ViewTransition promises in spec-compliant order.
  • Element-Scoped View Transitions: Element.prototype.startViewTransition(), activeViewTransition, and transitionRoot with concurrent and enclosing transitions.
  • View Transition Types & Granular Registration: Keeps native document.startViewTransition() intact and only mocks missing pieces.

Try the interactive demos below, or read the full documentation and source code on GitHub.

Getting Started

Install the package using your favorite package manager:

npm i view-transitions-mock

Import and call register() once before invoking startViewTransition(): 

import { register } from "view-transitions-mock";

register();

By default, registration checks for native support of Document View Transitions, View Transition Types, and Element-Scoped View Transitions, mocking only what is missing. Pass { forced: true } to force the mock in any browser, or check the demos below to see it in action.
